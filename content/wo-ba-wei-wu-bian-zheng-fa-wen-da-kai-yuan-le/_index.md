今天把一个做出来挺久的一个小东西开源了，叫「唯物辩证法问答」。

就是一个 AI 问答工具，但核心是唯物辩证法，不管你问什么问题，他都会从唯物辩证法的角度帮你拆解。

你问它"我该不该辞职"、"跟对象最近老吵架，到底是阶段性冲突还是根子上走不下去了"，它会用唯物辩证法那套思路，抓主要矛盾、具体问题具体分析、看矛盾转化到了哪个阶段，帮你把事情拆开看清楚。

它跟普通 AI 聊天不太一样的地方是，它不和稀泥。不会跟你说"两方面都有道理，关键看你自己怎么想"，它是真的敢下判断的。而且每次回答完，它还会告诉你这个判断是怎么推出来的，用了哪几条分析路径，对应你原话里的哪一句。这一点我自己挺得意的。

这个东西最早是给《毛选生活指南》的订阅读者做的福利。当时的想法很简单：专栏一直在讲怎么用毛选的方法论处理生活里的事，那不如做个能直接上手的工具，大家遇到纠结的事就扔进去拆一拆。最初的版本是内置 API 的，读者点开就能用，费用我来出。

结果呢，说实话，用的人不多。

这就有点尴尬了。继续养着吧，又没人用；当成一个正经项目维护吧，本身它就是一个Skill，又觉得没什么必要。

这东西最值钱的部分其实就是那套提示词，我调了很久的一套分析框架，藏起来也没什么意思。所以今天又把它翻出来，干脆一不做二不休：开源。

顺手把用法也改了。现在是自带 key 的模式，你填自己的 DeepSeek API key，花自己的 token，我也不用垫钱了（笑）。

虽然数据上挺冷清的，但我自己其实挺爱用它。主要是它经常帮我发现一件事：我以为自己在纠结 A 还是 B，让它拆完才发现，这根本就是个假二选一，真正的解法在 C。人陷在自己的问题里的时候，是很难看到这一层的。
