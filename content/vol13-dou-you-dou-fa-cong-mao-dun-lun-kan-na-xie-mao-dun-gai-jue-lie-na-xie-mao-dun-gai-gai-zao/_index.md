# 斗争的形式

上一篇结尾，我留了个问题：斗争既然是绝对的，从头到尾没停过，那对立的双方，是不是一定要拼个你死我活？

先把我的答案亮出来：不用。而且我为这个答案交过两回学费，一回是斗得太狠，一回是斗得太软。

斗得太狠的那次，是减脂。刚开始减的时候，节食节得很猛，训练强度也上得太大，两头一起夹，身体很快就顶不住了，抵抗力下降，经常感冒，出了一堆问题。

斗得太软的那次，是游戏。以前玩电脑游戏总是断断续续，玩的时候心里不踏实，甚至有点痛苦，觉得自己在浪费时间。这个状态拖了很久，直到后来我做了一个决定——把家里那台 Windows 主机直接卖掉。

一件事，我把自己斗垮了；另一件事，我斗得太客气，白白耗了很久。两笔学费合起来，刚好就是《矛盾论》最后要讲的那件事：斗争的形式。

## 斗是躲不掉的，斗法是可以选的

《矛盾论》到「对抗在矛盾中的地位」这一节，已经快收尾了。毛泽东在这里回答的，正是上面那个问题。他的话说得很干脆：

> 对抗，只是矛盾斗争的一种形式，而不是矛盾斗争的一切形式。[^1]

对抗，就是我们通常想象的斗争：摊牌，翻脸，最后统一体炸开，两方彻底分家。革命是这种形式，战争也是。往小了说，卖掉一台主机，同样是这种形式。

但毛泽东说，这**只是**一种。紧接着他把话说全了：

> 矛盾和斗争是普遍的、绝对的，但是解决矛盾的方法，即斗争的形式，则因矛盾的性质不同而不相同。

前半句接住了上一篇——斗是躲不掉的，没有余地。后半句是新东西：斗法可以选，而且必须选，选的依据是矛盾的性质。

性质怎么分？粗略地说就两类。一类矛盾，双方的根本利益冲突，调和不了，共存一天难受一天——这是对抗性的，解法就是决裂。另一类矛盾，双方其实在同一条船上，冲突是真的，但根本利益一致——这是非对抗性的，解法是调整和改造，把关系理顺，让两方继续在一个统一体里往前走。

毛泽东举的例子是党内的思想分歧。同志之间有不同意见，这是矛盾，也一直在斗，但用的是批评和讨论，用不着枪。Vol.09 那张表里就有这一行：共产党内的矛盾，用批评和自我批评解决[^2]。他同时提醒了一句：这两类矛盾中间的墙不是死的——非对抗性的处理不好，会激化成对抗性的；对抗性的条件变了，也可能缓和下来。

**斗争是绝对的，斗法是具体的；矛盾是什么性质，就用什么斗法。**

这句话看着平常，但它拦住的是两种最常见的错。用对抗的斗法去斗非对抗的矛盾，会把自己人打成敌人，把小事斗成大事。用非对抗的斗法去斗对抗的矛盾，等于拿商量去对付一个不容商量的东西，只会被一步步拖着走。

我那两笔学费，一边一个，正好把这两种错都交齐了。

## 我把身体当成了敌人

先说减脂那次。

刚开始减脂的人多半有一股狠劲，我当时也一样。热量往死里压，训练强度往死里上，恨不得一个月把一年的活干完。这么干的时候，心里那个逻辑听着还挺顺：脂肪是敌人，对敌人就该往死里打。

问题是，脂肪长在我自己身上。我跟我的体重之间，压根没有你死我活的关系。身体想活得舒服，我想瘦下来，两个目标看着打架，其实是一头的——瘦下来本来就是为了让这副身体更好地活着。这是一对彻头彻尾的非对抗性矛盾，它要的斗法是调整，是改造，把吃和练理顺，让身体一点点跟上来。

我却按敌我矛盾的打法开了战。结果前面说了，身体先垮，抵抗力下降，经常感冒，减脂这件事本身也被拖累。仗打得越狠，输得越快，因为我轰的是自己的补给线。

后来把整个思路换掉，改成生活化减脂。热量缺口留得温和一点，训练强度配着身体恢复来，该歇的时候老老实实歇。节奏慢了，但整个人稳住了，体重也在往下走。这套打法没有任何一天是激烈的，可它赢了。

**非对抗性的矛盾，赢法本来就不是打垮对方。** 对方垮了，你也就垮了。

## 那台主机，就该卖

游戏这件事，性质刚好反过来。

断断续续地玩，本质上是想跟游戏和平共处：想玩的时候玩一会儿，该干正事的时候停下来，两边商量着来。这个方案我执行得很失败。玩的时候不踏实，心里总有个声音说你在浪费时间；停下来一阵，手又痒。它不像爱好，倒像一场谈不拢又散不了的谈判。

现在回头看，这场谈判注定谈不拢。我想要的状态和游戏占走的东西，在我这里就是调和不了，每一次「适度地玩」都在给这个矛盾续命。这是一对对抗性的矛盾，对付它的正确形式，从一开始就写好了：决裂。

所以卖掉主机那一下，看着极端，其实是这件事里我做过最对的一个动作。它没有去调整我跟游戏的关系，它直接把「我和游戏共处一室」这个统一体给拆了。环境一断，那场没完没了的谈判自动终止，之后我的状态好了很多。

我后来把这个心得总结成一句话：培养习惯这件事，**与其断断续续，不如彻底不做。** 断断续续听着温和，其实最耗人，因为它让一个该决裂的矛盾永远悬着，天天开庭，永不宣判。

两件事放在一起，道理就出来了。同一个我，同样在跟自己较劲，一件事该温和我用了狠的，一件事该狠我用了温和的，两头都吃了亏。**斗法用错了方向，力气越大，亏吃得越大。** 而斗法对不对，判断只有一条：先看清这对矛盾到底是什么性质。这就回到了 Vol.09 的那把钥匙和那把锁——**定性，永远在斗法前面。**

## 文驰做到收尾，斗法也换了

还有一层，是我正在经历的。

我在开发一款自己的产品，文驰，一个帮人写长篇小说的写作工具。Vol.10 里写过做它时的一段狼狈，这里接着说后来。

前期的开发，斗法只能是硬的。问题成堆，每一个都挡在路中间，绕不过去，只能投入大把时间和精力，一个一个往下啃。那个阶段如果跟自己说慢慢来，等于什么都做不成。

现在到了收尾阶段。大的框架立住了，剩下的活是完善细节，把每一处慢慢磨顺。这个阶段再用攻坚的打法，反而要坏事：细节是磨出来的，急不得，越想毕其功于一役，越容易把已经立好的东西改乱。

同一款产品，同一个人在做，前期和后期的正确斗法完全相反。原因就是毛泽东提醒过的那一句：矛盾的性质会变。前期的主要矛盾是难题挡路，它尖锐，得用尖锐的方式对付；框架立住之后，矛盾换成了粗糙和完善之间的差距，它温和，就得用温和的方式对付。**斗法不光要配矛盾的性质，还得跟着性质的变化一起换。**

上一篇说平衡会一个接一个地破。这一篇补上后半句：每破一次，都值得重新问一遍——现在这个矛盾，还是原来那个性质吗？

## 七篇文章，一个框架

写到这，《矛盾论》这个系列就到头了。回头把七篇串起来，其实是把一个问题一层层问到底：


| 篇      | 问的是什么      | 《矛盾论》的回答              |
| ------ | ---------- | --------------------- |
| Vol.07 | 事情为什么会变    | 根子在内部矛盾，外因通过内因起作用     |
| Vol.08 | 矛盾是偶发的吗    | 事事有矛盾，时时有矛盾           |
| Vol.09 | 办法能通用吗     | 每个矛盾各有性质，一把钥匙开一把锁     |
| Vol.10 | 一堆矛盾先抓哪个   | 抓住主要矛盾，其余迎刃而解         |
| Vol.11 | 一对矛盾里谁说了算  | 占主导的一方定性质，主导权会换边      |
| Vol.12 | 对立的两方是什么关系 | 互相依存，共处一体，合是暂时的，斗是永远的 |
| Vol.13 | 那到底该怎么斗    | 斗法配性质，该改造的改造，该决裂的决裂   |


Vol.07 开篇问的是，世界为什么会变。到这一篇，答案算完整了：因为万事万物内部都有矛盾，矛盾的双方一直在斗，斗着斗着，主导权换了边，平衡跟着破掉，旧的统一体让位给新的，事情就变了。变化没有终点，因为斗争没有终点。

这听起来像一个冷冰冰的世界观，但这几个月把它一篇篇写下来，我自己的感受恰恰相反。Vol.09 收尾时写过一句：普遍性让你不慌，特殊性让你不懒。现在可以把后半截补上了——主要矛盾、主要方面、同一性、斗争形式，这几篇合起来给的是一套下手的顺序：先找到矛盾在哪，弄清它是什么性质，接着看一堆矛盾里谁是主要的、一对矛盾里谁占着上风，最后按性质选斗法。

这套顺序，就是《矛盾论》留给一个普通人的全部家当。它不替你解决任何一个具体的问题，但你遇到的每一个具体的问题，都可以从它这里领到一个开头。

在 Vol.03 的结尾我说过，要先把《实践论》和《矛盾论》这两块基石打完，再去拆第一卷里其他的文章。到今天，这个承诺算是兑现了。《实践论》讲认识怎么来、怎么检验，《矛盾论》讲世界怎么动、怎么变。一个管想明白，一个管看明白。

往后的文章，就是带着这两件工具，回到第一卷那些具体的篇目里去了。

**世界不会停止变化，但看懂变化的人，可以不被它拖着走。**
