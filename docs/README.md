# xiluluke.com 维护资料

换电脑或让新的 AI 接手时，按以下顺序阅读：

1. [`MAC-HANDOFF.md`](./MAC-HANDOFF.md)：Mac 首次安装、AI 工作边界、分支发布和验收清单。
2. [`xiluluke-mac-ai-handoff-guide.pdf`](./xiluluke-mac-ai-handoff-guide.pdf)：适合人阅读的 Mac 与 AI 交接手册。
3. [`xiluluke-site-maintenance-manual.pdf`](./xiluluke-site-maintenance-manual.pdf)：完整的网站同步、首页运营、产品、封面、部署、域名与排障手册。
4. 仓库根目录的 `SITE-OPERATIONS.md`、`HOMEPAGE-OPERATIONS.md` 和 `COVER-OPERATIONS.md`。

`.jant-sync` 是判断 Jant 文件所有权边界的最终依据，应在任何修改前优先阅读。
